\### Опис програми

Програма реалізує інтерактивний інструмент для генерації гармонійного сигналу вигляду $y(t) = A \\cdot \\sin(\\omega t + \\varphi)$ із можливістю накладання гауссового шуму та його подальшої фільтрації за допомогою низькочастотного фільтра Баттерворта 5-го порядку.



\*\*Особливості реалізації:\*\*

\- \*\*Кешування шуму:\*\* При зміні параметрів гармоніки (амплітуда, частота, фаза) малюнок шуму залишається незмінним і не перегенеровується. Шум змінюється виключно за умови редагування його власних параметрів (середнє значення, дисперсія).

\- \*\*Інтерактивні елементи:\*\* Використано слайдери `matplotlib.widgets` для плавного налаштування сигналу та фільтра в реальному часі.



\### Інструкція для користувача

1\. \*\*Керування сигналом:\*\* Використовуйте ліві слайдери ("Амплітуда", "Частота", "Фаза") для зміни форми базової гармоніки.

2\. \*\*Керування шумом:\*\* Слайдери "Сер. шум" та "Дисп. шум" відповідають за математичне очікування та варіацію накладеного шуму відповідно.

3\. \*\*Фільтрація:\*\* Слайдер "Зріз фільтра" налаштовує частоту зрізу фільтра Баттерворта. Зменшуйте його для кращого відсікання високих частот шуму.

4\. \*\*Чекбокси:\*\* Перемикач "Відображати шум" вмикає/вимикає генерацію зашумленого сигналу. "Показувати фільтр" — керує відображенням результату обробки на нижньому графіку.

5\. \*\*Кнопка Reset:\*\* Повертає систему до початкових дефолтних налаштувань.
